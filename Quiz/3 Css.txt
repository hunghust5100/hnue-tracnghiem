Câu 1: Thuộc tính "margin" trong CSS được dùng để làm gì khi áp dụng cho một HTML element?

A. Thiết lập độ dày của đường viền (border thickness)

B. Thiết lập khoảng căn lề (padding)

C. Thiết lập kích thước chữ

*D. Thiết lập khoảng trắng bên ngoài đường viền

Giải thích: `margin` tạo ra khoảng không gian nằm bên ngoài đường viền (border) của phần tử.




Câu 2: Thuộc tính CSS nào dùng để thay đổi màu của text?

A. font-color

B. text-color

*C. color

D. textColor

Giải thích: `color` là thuộc tính chuẩn để định dạng màu chữ trong CSS.




Câu 3: Đâu là cú pháp đúng để khai báo một external CSS file trong trang web?

A. <style src="styles.css">

*B. <link rel="stylesheet" href="styles.css">

C. <css href="styles.css">

D. <link src="styles.css">

Giải thích: Thẻ `<link>` với thuộc tính `rel="stylesheet"` và `href` là cú pháp chuẩn để nhúng file CSS bên ngoài.




Câu 4: Cú pháp CSS style nào sau đây không nên sử dụng cho các thiết kế HTML responsive?

A. float: right;

B. visibility: hidden;

C. display: none;

*D. position: absolute;

Giải thích: `position: absolute;` gỡ phần tử khỏi luồng tài liệu chuẩn, làm mất tính linh hoạt khi khung nhìn thay đổi kích thước.




Câu 5: Trong thiết kế responsive bằng CSS flexbox, thuộc tính "gộp" flex được dùng để làm gì?

*A. Cùng lúc thiết lập các giá trị flex-grow, flex-shrink và flex-basis

B. Thiết lập flex container

C. Thiết lập thứ tự của các flex items xuất hiện trong container

D. Kiểm soát hướng xuất hiện của các flex items trong container như là flex-direction

Giải thích: `flex` là thuộc tính viết tắt (shorthand) gộp chung cho `flex-grow`, `flex-shrink` và `flex-basis`.




Câu 6: Giá trị mặc định của thuộc tính position là gì?

A. sticky

*B. static

C. absolute

D. fixed

Giải thích: Mọi phần tử HTML mặc định đều ở trạng thái `position: static`.




Câu 7: Trong thiết kế responsive bằng CSS flexbox, cú pháp nào thiết lập cố định đối tượng ở giữa theo chiều dọc?

A. margin: auto;

B. position: absolute; top: 50%;

*C. display: flex; align-items: center;

D. vertical-align: center;

Giải thích: `align-items: center;` trong flex container căn giữa các phần tử theo trục chéo (cross axis).




Câu 8: Để thiết lập CSS style cho HTML element có ID là "example" thì cú pháp selector là gì?

Câu 9: Để áp dụng nhiều CSS style cho cùng một đối tượng HTML, cú pháp nào là đúng?

Câu 10: Để đặt bóng đổ (shadow) cho các thành phần HTML thì sử dụng cú pháp CSS nào?

A. shadow-color: grey;

B. alpha-effect[shadow]: 10px 10px 5px grey;

C. shadow-right: 10px shadow-bottom: 10px;

*D. box-shadow: 10px 10px 5px grey;

Giải thích: `box-shadow` là thuộc tính tạo hiệu ứng bóng đổ cho hộp (box) phần tử.




Câu 11: Định nghĩa style box như sau: div { box-sizing: content-box; width: 20px; padding: 2px; margin: 3px; border: 1px; } Hỏi chiều rộng thực tế khi browser hiển thị phần tử <div> này là bao nhiêu?

A. 24px

*B. 26px

C. 30px

D. 32px

Giải thích: Với `content-box`, chiều rộng thực = width (20) + padding trái/phải (2*2) + border trái/phải (1*2) = 26px. Margin không tính vào kích thước box.




Câu 12: Thiết lập CSS thế nào để định dạng một border với: The top border = 10px, The bottom border = 5px, The left border = 20px, The right border = 1px

A. border-width: 10px 5px 20px 1px;

B. border-width: 5px 20px 10px 1px;

*C. border-width: 10px 1px 5px 20px;

D. border-width: 10px 20px 5px 1px;

Giải thích: Cú pháp rút gọn đọc theo chiều kim đồng hồ: Top (10px) - Right (1px) - Bottom (5px) - Left (20px).




Câu 13: Đâu là cú pháp đúng để thực hiện tạo hiệu ứng khi chuyển tiếp (transition) một HTML element với CSS?

A. alpha-effect: transition (width, 2s);

B. transition-duration: 2s; transition-effect: width;

*C. transition: width 2s;

D. Tất cả đều sai

Giải thích: Cú pháp rút gọn chuẩn là `transition: [thuộc tính] [thời gian];`.




Câu 14: Để tạo viền (border) cho một ảnh thì sử dụng cú pháp CSS nào?

Câu 15: Để tạo box có góc bo tròn (rounded corner) thì sử dụng cú pháp CSS nào?

Câu 16: Diễn giải nào dưới đây đúng với luật CSS selector sau: .first.info#title {}

*A. Phần tử có ID="title", có lớp là "info", thuộc bên trong lớp "first"

B. Phần tử có ID="title", là con lớp "info", thuộc bên trong lớp "first"

C. Phần tử thẻ <first">, có lớp là "info" có con có ID="title"

D. Phần tử có ID="title", có lớp là "first", thuộc bên trong lớp "info"

Giải thích: Selector `.first.info#title` nhắm vào một phần tử duy nhất thỏa mãn đồng thời 3 điều kiện (id và 2 class). Trong các phương án, đáp án A phản ánh gần nhất ý đồ bài toán dù cách diễn đạt "thuộc bên trong" chưa thật chuẩn xác.




Câu 17: Để lựa chọn các HTML element <p> là con trực tiếp của <div> ta sử dụng selector nào:

B. div + p

C. div ~ p

D. div p

Giải thích: Ký tự `>` là toán tử chọn phần tử con trực tiếp (direct child selector).




Câu 18: Để chọn thành phần <p> là con trực tiếp của <div> thì cần sử dụng selector nào?

A. div + p

B. div ~ p

Giải thích: Tương tự câu 17, `>` dùng để chọn child trực tiếp.

Câu 31: Diễn giải nào dưới đây đúng với luật CSS selector sau: section.dark img.large {}

*A. Phần tử thẻ <img> với lớp "large" là con của phần tử thẻ <section> với lớp "dark"

B. Phần tử thẻ <section> với lớp "dark" là tổ tiên của phần tử thẻ <img> với lớp "large"

C. Phần tử thẻ <img> với lớp "large" là con trực tiếp của phần tử thẻ <section> với lớp "dark"

Giải thích: Ký tự khoảng trắng thể hiện quan hệ phần tử con cháu (descendant). <img> nằm ở cấp bất kỳ bên trong <section>.
