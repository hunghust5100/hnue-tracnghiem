Câu 38: Cần xây dựng hàm asynchronous asyncFunc() thực hiện giả lập các hoạt động asynchronous và trả về thông báo "Done" khi hoàn thành. Những phương pháp khai báo nào sau đây là phù hợp với yêu cầu trên?

*A. function asyncFunc() { return new Promise((resolve) => { setTimeout(() => resolve("Done"), 1000); }); }

*B. async function asyncFunc() { return new Promise((resolve) => { setTimeout(() => resolve("Done"), 1000); }); }

C. async function asyncFunc() { return ("Done"); }

D. function asyncFunc() { return ("Done"); }

Giải thích: Phương án A và B sử dụng đối tượng `Promise` phối hợp với tác vụ hẹn giờ `setTimeout` để tạo ra sự trì hoãn không đồng bộ thực sự mô phỏng hành vi xử lý nền, sau đó mới giải quyết chuỗi dữ liệu. Phương án C và D trả kết quả đồng bộ ngay lập tức không có tính chất trì hoãn giả lập hoạt động bất đồng bộ kéo dài.




Câu 39: Các phát biểu đúng về cơ chế prototype trong JavaScript?

*A. prototype là một thuộc tính của Object

*B. mỗi JavaScript object đều có một prototype cài đặt các phương thức của mình

*C. các JavaScript object sử dụng thuộc tính prototype để tham chiếu (reference) đến class của mình

D. thuộc tính __proto__ của mỗi object tham chiếu đến native code của object

Giải thích: Mọi thực thể đối tượng đều thừa hưởng các thuộc tính, phương thức từ một đối tượng nguyên mẫu nguyên thủy. Hàm khởi tạo (constructor function) có thuộc tính `.prototype` công khai, đối tượng cụ thể có liên kết ẩn truy vết ngược lại lớp cơ sở. Thừa số `__proto__` trỏ tới prototype của cha chứ không trỏ tới mã máy.
