# Bộ câu hỏi trắc nghiệm nâng cao - Môn Giáo dục học (ĐHSP)

Thư mục lưu trữ ngân hàng câu hỏi trắc nghiệm nâng cao môn Giáo dục học (Mức độ Vận dụng và Vận dụng cao), bao gồm:
1. **Dạng 1**: Trắc nghiệm 4 lựa chọn (Chọn 1 đáp án đúng duy nhất A, B, C, D).
2. **Dạng 2**: Trắc nghiệm Đúng / Sai (Mỗi câu gồm 4 mệnh đề a, b, c, d; xác định Đúng hoặc Sai cho từng mệnh đề).

## Quy chuẩn biên soạn:
- Tuyệt đối không sử dụng đáp án ngô nghê/dễ đoán.
- Tất cả phương án nhiễu đều là mệnh đề/luận điểm chuẩn thuật ngữ sư phạm nhưng gài bẫy logic (tráo đổi vai trò, tráo đổi môi trường, tráo đổi bản chất quy luật/nguyên tắc).
- Có phần giải thích chi tiết 3 phần: Bản chất đáp án đúng, Phân tích bẫy nhiễu, Quy luật suy luận mở rộng.
